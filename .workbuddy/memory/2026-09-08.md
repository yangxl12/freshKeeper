## 修复 quick-entry 页面 WXSS 编译报错

- 现象：微信开发者工具报 `[ WXSS 文件编译错误] ./pages/quick-entry/index.wxss(134:14): error at token *`。
- 原因：WXSS 不支持通用选择器，`.field-row > * { min-width: 0; flex: 1; }` 无法解析。
- 处理：
  - `index.wxss:134` 改为 `.field-row__item { min-width: 0; flex: 1; }`。
  - `index.wxml` 中两处 `.field-row` 的 4 个直接子元素补上 `field-row__item` 类（保质期输入框、单位 picker、数量/单位两个 `view.field`），保持原本的等分弹性布局。
- 验证：`npm run check` 全绿（tsc 无错、38 个测试通过、项目结构校验通过）。

## 修复 vitest 全量测试失败（环境）

- 现象：`npm run check` 里 11 个测试文件全挂，报 `TypeError: Cannot read properties of undefined (reading 'config')`，
  或 `Vitest failed to find the current suite`（@vitest/runner 的 runner 全局状态为空）。
- 排查：清 `node_modules/.vite`/`.vite-temp` 无效（只能偶尔让单次运行碰巧通过）；换 node 22/24、换 pool、关沙箱、
  摘掉 NODE_OPTIONS 注入的 node shim 都无效；把项目整目录复制出去跑结果同样失败，说明与目录无关。
- 结论：vitest 5.0.0（仓库原版本）和 4.1.11（配 vite 7.3.6 / 8.2.2）在本机都会把 runner 模块加载成两份。
  降到 **vitest 3.2.7**（并移除 package.json 里显式锁的 vite）后稳定：11 文件 / 81 测试连续三次全过。
