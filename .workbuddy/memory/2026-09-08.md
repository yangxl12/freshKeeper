## 修复 quick-entry 页面 WXSS 编译报错

- 现象：微信开发者工具报 `[ WXSS 文件编译错误] ./pages/quick-entry/index.wxss(134:14): error at token *`。
- 原因：WXSS 不支持通用选择器，`.field-row > * { min-width: 0; flex: 1; }` 无法解析。
- 处理：
  - `index.wxss:134` 改为 `.field-row__item { min-width: 0; flex: 1; }`。
  - `index.wxml` 中两处 `.field-row` 的 4 个直接子元素补上 `field-row__item` 类（保质期输入框、单位 picker、数量/单位两个 `view.field`），保持原本的等分弹性布局。
- 验证：`npm run check` 全绿（tsc 无错、38 个测试通过、项目结构校验通过）。
