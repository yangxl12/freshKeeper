- 需求：首页卡片点进详情，详情页也要显示那张 AI 封面，「直接复用」。
- **可行性结论：可以直接复用，零后端改动。** 数据层早就通了：云端 `publicItem()`
  是「白名单外全量带出」，`coverFileId` 一直在返回里；客户端 `coverThumbUrl()` 现在
  就是原 fileID（`COVER_THUMB_QUERY` 为空），所以列表和详情拿到的是同一个字符串。
  ⚠️ 前提仍然是**不拼任何展示层参数**（拼了就是 `file not found`，09-13 踩过）。
- 唯一真问题是**时机**：封面是保存后 fire-and-forget 生成的，点进详情时可能还没就绪。
  解法是复用首页那套 `onItemCoverReady` 订阅，只认自己这件物品。

改动（`miniprogram/pages/item-detail/`）：
- `decorateItem` 加 `coverUrl: coverThumbUrl(item.coverFileId)` —— 复用 `domain/inventory`

- 淡入刻意用 CSS `animation` 而不是 `opacity:0` 初始态：万一某机型不触发 `bindload`，
  图只是少了入场动画，而不是像 09-13 那样直接隐身。

## 探针（skill 已同步更新）

- **手写 WS 调用 `params` 不能省**：`{id, method}` 会 timeout，白排查一轮；`probe.mjs` 默认传 `{}` 所以没这问题。
- `Page.getData` 必须显式带 `{pageId}`，不带报 `page destroyed`（不是自动取当前页）。
- 同一响应服务端会**重复发两遍**，多路复用要按 id 去重。
- `getImageInfo` 只认网络/云路径，包内路径（`/assets/*.svg`）返回 `invalid`，**不代表资源坏了**。
- `App.callWxMethod` 的 `args` 形态：`reLaunch`/`navigateTo` 用 `args:[{url}]`，
  `getImageInfo` 用 `args:[{src}]` —— **参数要包一层对象再放进数组**。

## 详情页封面闪动修复（状态机 + 常驻占位图）

- 现象：进详情页时封面「闪一下」。**根因是上一版的淡入动画自己造成的**：
  真图静默态是 `opacity:1`，`bindload` 后加 class 播 `cover-fade-in`（`from opacity:0`），
  等于「图片先以不透明渲染出来 → 被动画拉回全透明 → 再淡入」。缓存命中时 `bindload`
  几乎同帧触发，闪得最明显。
- 修法三条，缺一不可：
  1. **透明做静态初始态**：`.hero__cover-img { opacity: 0; transition: opacity 220ms }`
     + `--ready { opacity: 1 }`。动画起点不再需要「抹掉已显示的内容」。
  2. **兜底占位图常驻最底层**（`hero__cover-fallback`，绝对定位铺满），
     这样才敢让真图初始透明 —— 上一版不敢用 `opacity:0` 就是因为「怕不触发 bindload 就隐身」，
     有了常驻垫底这层顾虑就不存在了。
  3. **转圈过渡层**（`.hero__cover-spinner-ring`，CSS `border` + `rotate`，不用图片资源），
     只在 `coverStatus === 'loading'` 时 `opacity:1`，不做 `wx:if`（保留淡出）。
- 状态机替代原来的 `coverLoaded` / `coverFailed` 两个布尔：
  `idle | loading | ready | failed`。两个布尔会造出「已就绪又被打回加载中」的矛盾中间态。
- **`loadItem` 里只在 `coverUrl` 变化时才改 coverStatus**：`onShow` 会重跑 `loadItem`，
  无脑重置成 loading 会让已经显示好的图每次进页面都重播淡入 —— 那就是另一个闪动源。
- `onItemCoverReady` 回填同样加「同一张图直接 return」，避免无意义 setData 让 `<image>` 白走一遍加载。
- 兜底定时器 `COVER_REVEAL_FALLBACK_MS = 2500`：`bindload` 万一不触发，转圈别转到天荒地老；
  到点还是 `loading` 就置 `ready`（占位图顶上来）。`onUnload` 必须 `clearTimeout`。
