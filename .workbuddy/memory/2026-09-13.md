## 修复：最近档案把回收站物品拉进推荐（第五批续）

龙哥问索引怎么建，重读第 10 项代码时发现**回归 bug**：

`readRecentProfilesOnce` 的 query 写成了 `where({ ownerId })`，**没过滤 `inventoryStatus`** →
回收站（`deleted`/`discarded`）的物品会进快录页的「最近录入档案」建议，用户在清空回收站前会一直看到删掉的东西。
原双状态 fallback 只取 active/used_up，是改造时漏掉的语义差异，**单测也没覆盖**（测试数据没有 deleted 物品）。

修法：
- `recent.js` 导出 `PROFILE_STATUSES = ['active','used_up']`
- `listRecentProfiles` 查询加 `inventoryStatus: command.in(PROFILE_STATUSES)`
- `mergeRecentItems` 再加一道**黑名单**兜底 `EXCLUDED_STATUSES`（用黑名单不用白名单 ——
  缺 `inventoryStatus` 字段的历史文档不该被顺手扔掉，否则现有测试数据会被全滤掉）
- 补一条「回收站物品不进最近档案」用例

**顺带省掉一条索引**：加了状态条件后命中**已存在**的老索引 `ownerId+inventoryStatus+updatedAt DESC`
（cloud-deployment.md 索引表第 7 行），于是 `ownerId+updatedAt DESC` 不用建了，已从索引表撤下。
现在真正待建的只剩 `ownerId+inventoryStatus+name` 一条（服务于 `image-cover.js` 同名复用查询）。

## 索引怎么建（已写进 cloud-deployment.md 2.1 节）

索引**不在代码里，也没有 API 能建**，只能去云开发控制台点：
开发者工具 →「云开发」→ 数据库 → 集合 → **索引管理** → 添加索引；或网页 <https://cloud.weixin.qq.com>。
坑：**选对环境**（开发/生产各建一次，漏了生产是静默全表扫）、**字段顺序不能换**、
**别勾唯一**（ownerId 是重复值）。控制台不提供 `explain`，验证只能靠日志 `durationMs` + 数据库读次数监控。

## 索引：确认无法自动化，只能手点

龙哥嫌手点烦，让用微信开发者工具 MCP 代劳。**查完结论是建不了**（已记进 MEMORY.md，别重复调研）：
`cli.bat cloud` 只有 `env`/`functions`，没有 database；MCP 只覆盖小程序端自动化；
腾讯云 CloudBase manage-node 要密钥而本机没有；微信云开发 HTTP API 没有索引管理。

另外从龙哥截图确认：当时索引管理里只有 4 条（`_id`、`_openid_1`、刚建的 `ownerId_status_name`、
疑似字段名写成小写 `ownerid` 的 `ownerid_updatedAt`）——**索引表里 11 条实际只建了 1 条**。

## 环境补充

- `git commit -F -` 在本机 PowerShell 工具下拿不到 stdin（会当成 pathspec）。
  **改用 Write 工具写 `.commitmsg.txt`（UTF-8）再 `git commit -F .commitmsg.txt`**，中文不乱码。
- PowerShell 控制台回显中文会乱码（UTF-8 字节被按 GBK 解），但**落盘的提交信息是好的**。
  想看清输出先设 `$OutputEncoding=[Console]::OutputEncoding=[Text.Encoding]::UTF8`。

## 新增 docs/launch-checklist.md（后台手工操作汇总）

龙哥问「隐私协议之类要我操作的有哪些」。原来这些散在 6 个文档里，逐份 grep 才拼得齐，于是新写

  `scope.record`/`scope.camera`，不能用无效配置代替后台指引。
- **B 订阅消息模板**：`runtime.ts:15` 仍是 `TODO_REPLACE_WITH_REAL_TEMPLATE_ID`，**提醒实际发不出去**。
  模板 ID 要填 3 处（runtime.ts / reminderApi 环境变量 / dispatchReminders template.js），
  字段名以实际审批结果为准（当前假定 thing7/time2/number5/number4/thing3），
  另有各投放阶段的 `MINIPROGRAM_STATE`。
- **C 腾讯云**：开通一句话识别 + 通用文字识别（高精度版）并配密钥；报名小程序成长计划；

- **D 云开发控制台**：11 条索引（开发+生产各一次）、4 个集合权限设「无权限」、
  云函数超时 60s（quickEntryApi / userApi）、dispatchReminders 与 cleanupTrash 禁客户端调用、
