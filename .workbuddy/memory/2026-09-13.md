## 环境补充

- `git commit -F -` 在本机 PowerShell 工具下拿不到 stdin（会当成 pathspec）。
  **改用 Write 工具写 `.commitmsg.txt`（UTF-8）再 `git commit -F .commitmsg.txt`**，中文不乱码。
- PowerShell 控制台回显中文会乱码（UTF-8 字节被按 GBK 解），但**落盘的提交信息是好的**。
  想看清输出先设 `$OutputEncoding=[Console]::OutputEncoding=[Text.Encoding]::UTF8`。
