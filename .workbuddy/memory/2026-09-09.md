# 2026-09-09

## UI 三处修复

- **自定义 tab 栏加号被裁**：原实现把圆形放在 `button.tabbar__add`（高 104rpx）里用 `margin-top: -30rpx` 顶上去，
  微信 `wx-button` 基础样式带 `overflow: hidden`（且 tabBar 容器也可能裁剪），凸起部分被切掉。
  改法：加号按钮从 bar 里拿出来，`position: fixed` + `left/right: 0` + `margin: 0 auto` 居中，
  `overflow: visible; z-index: 1000`；圆形 100rpx，`bottom: calc(54rpx + env(safe-area-inset-bottom))`，
  圆心正好落在 bar 顶边（104rpx）→ 上半圆完整凸出。bar 内用 `.tabbar__add-slot`（flex 0 0 150rpx）占位。
  **结论：自定义 tabBar 的凸起元素不要靠负 margin 溢出父级，单独 fixed 定位最稳。**
- **批量操作页标题**：导航栏标题固定 `批量操作`；页内标题按实际筛选状态算
  （`VIEW_STATUS_TITLE`: active_all 全部在库 / expiring 临期 / expired 已过期 / safe 状态良好 / used_up 已用完 / trash 回收站）。
  之前只按 `source` 取值，从首页进来恒为「临期物品批量操作」。
- **快速录入拍日期提示**：OCR 未接入时保留按钮，提示由「暂时未接入，敬请期待」改为
  「拍照识别未开通，请手动选日期」；语音仍用原文案。常量 `DATE_PHOTO_PENDING_TOAST`。

校验：`npm run check` 全绿（11 文件 83 测试 + 项目结构检查）。

## 快速录入彻底梳理（第二轮）

用户反馈：最近使用录入不可用、日期录入弹莫名其妙提示。最终改动：

- **语音 / 拍日期改为「显示但禁用」**：删掉 `PENDING_INTEGRATION_TOAST`、`DATE_PHOTO_PENDING_TOAST` 与 `handleVoiceTap`；
  WXML 三个按钮 `disabled` 加 `!capabilities.voice` / `!capabilities.datePhoto`；`startVoice`、`chooseDatePhoto`
  未接入时直接 return（不 toast）。新增 `.feature-hint` 一行静态说明 + `[disabled]` 灰态样式。
  根因：微信 toast 标题 >7 汉字被截断，长文案显示成残缺的「鬼东西」。
- **最近使用修好**：`quick-entry-service.listRecentProfiles()` 遇 `INVALID_ACTION` 降级为 `listInventory` 本地归并
  （新增 `domain/quick-entry.ts` 的 `toRecentProfile` / `recentProfilesFromItems`）；最近使用区去掉 `!drafts.length` 条件，
  点击改为追加草稿（上限 5）。原来一旦生成过草稿，最近列表就永久消失，被当成功能坏了。
- **日期提示**：`expirySummaries[i] < today` 的中文占位串比较换成 `expiredFlags` 数组（先正则校验 YYYY-MM-DD）；
  两个 date picker 的 `value` 空串兜底为 `today`，避免空值定位异常。
- 新增测试 `tests/unit/quick-entry-recent.test.ts`（3 个）与 4 个页面链路测试；`npm run check` 12 文件 89 测试全绿。
