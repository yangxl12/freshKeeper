# 2026-09-09

## UI 三处修复

- **自定义 tab 栏加号被裁**：原实现把圆形放在 `button.tabbar__add`（高 104rpx）里用 `margin-top: -30rpx` 顶上去，
  微信 `wx-button` 基础样式带 `overflow: hidden`（且 tabBar 容器也可能裁剪），凸起部分被切掉。
  改法：加号按钮从 bar 里拿出来，`position: fixed` + `left/right: 0` + `margin: 0 auto` 居中，
  `overflow: visible; z-index: 1000`；圆形 100rpx，`bottom: calc(54rpx + env(safe-area-inset-bottom))`，
  圆心正好落在 bar 顶边（104rpx）→ 上半圆完整凸出。bar 内用 `.tabbar__add-slot`（flex 0 0 150rpx）占位。
  **结论：自定义 tabBar 的凸起元素不要靠负 margin 溢出父级，单独 fixed 定位最稳。**
- **批量操作页标题**：导航栏标题固定 `批量操作`；页内标题按实际筛选状态算
  （`VIEW_STATUS_TITLE`: active_all 全部在库 / expiring 临期 / expired 已过期 / safe 状态良好 / used_up 已用完 / trash 回收站）。
  之前只按 `source` 取值，从首页进来恒为「临期物品批量操作」。
- **快速录入拍日期提示**：OCR 未接入时保留按钮，提示由「暂时未接入，敬请期待」改为
  「拍照识别未开通，请手动选日期」；语音仍用原文案。常量 `DATE_PHOTO_PENDING_TOAST`。

校验：`npm run check` 全绿（11 文件 83 测试 + 项目结构检查）。
