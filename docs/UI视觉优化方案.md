# 保质期助手 UI 视觉优化方案

> 版本：V1.0 · 日期：2026-09-07

## 1. 优化目标

在不改变 MVP 功能与页面结构的前提下，解决当前界面视觉平均、重点不明、品牌识别弱的问题：

- 首页第一眼回答“今天有几件需要处理”；
- 用清晰的强、中、弱层级替代大量同质浅色卡片；
- 建立“家庭保鲜标签”的统一视觉语言；
- 保留清爽、可信、易读的基础，不用装饰堆砌设计感。

## 2. 当前问题

| 问题 | 当前表现 | 调整方向 |
| --- | --- | --- |
| 缺少视觉中心 | 标题、三项统计、搜索和列表权重接近 | 首页只保留一个强视觉区：今日待处理 |
| 层次偏平 | 页面普遍使用浅底、细边框、相近字号 | 建立深色主视觉、浅色功能区、无底内容区三级层级 |
| 卡片同质化 | 表单、详情、设置均是白色圆角框 | 只给重点模块容器，普通信息改用分组和留白 |
| 状态识别弱 | 状态主要依赖小圆点和文字颜色 | 状态同步影响数字、日期标签和局部背景，但不整卡染色 |
| 品牌感不足 | 现有绿色较克制，但缺少独有元素 | 以“保鲜标签”作为日期、状态和空状态的共同母题 |
| 操作主次不稳 | 详情页多个大按钮并列，视觉竞争 | 每个场景只突出一个主操作，危险操作降级并分隔 |

## 3. 视觉方向：家庭保鲜台

把首页理解为每天打开一次的“家庭保鲜台”，而不是库存后台。

### 3.1 核心视觉

首页顶部使用一张深松绿色的“今日待处理标签”：

- 大数字展示 `已过期 + 7 天内到期` 的品项数；
- 主文案固定为“今天先处理 X 项”；
- 已过期、临期拆为两个小标签，有效库存降为辅助信息；
- 加入极淡的标签切角、压纹线或日期戳，形成识别度，不使用插画大图。

这是全局唯一的强色大面积区域。其余页面保持安静，避免每个模块都抢注意力。

### 3.2 设计关键词

`新鲜`、`有序`、`可信`、`轻量家庭感`。

不采用高饱和渐变、玻璃拟态、大面积阴影或复杂图表；这些元素与“快速查看并处理临期物品”的任务无关。

## 4. 基础视觉规范

### 4.1 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 松针绿 | `#1F5D49` | 主视觉、主按钮、选中态 |
| 深墨绿 | `#173B31` | 标题、关键数字、深色区文字层级 |
| 薄荷白 | `#E8F2ED` | 选中态和保鲜信息弱背景 |
| 米灰白 | `#F5F6F2` | 页面背景，降低当前浅绿色泛灰感 |
| 琥珀橙 | `#C8792B` | 1～7 天临期提示 |
| 期限红 | `#B84A3E` | 已过期与危险操作 |

正文使用 `#53645D`，弱提示使用 `#84918B`。状态不能只靠颜色，始终保留文字。

### 4.2 字体与字号

- 品牌标题：`Songti SC / STSong`，只用于首页主句、表单页引导语、详情物品名；
- 正文与控件：`PingFang SC / Microsoft YaHei`；
- 日期与数字：`DIN Alternate / Arial Narrow`，统一数字宽度和节奏；
- 建议字号层级：主数字 `64rpx`、页面标题 `42rpx`、模块标题 `30rpx`、正文 `26rpx`、辅助信息 `22rpx`；
- 正文最小不低于 `22rpx`，标题不使用过多字重，靠字号、颜色和留白区分层级。

### 4.3 圆角、边框与阴影

- 主视觉卡：`28rpx` 圆角；
- 普通容器：`20rpx` 圆角；输入框、筛选项：`16rpx` 圆角；
- 普通边框统一为 `2rpx #DDE5E0`；
- 阴影只用于首页主视觉和悬浮新增按钮，列表、表单卡片不加阴影；
- 页面按 `8rpx` 网格组织，主要区块间距使用 `32/48rpx`。

### 4.4 图标

- 搜索、筛选、日期、位置、提醒、编辑统一为同一套 `2rpx` 线性图标；
- 不再混用 `⌕`、`⌄`、`›`、`×` 等不同风格的字符图标；
- 底部“库存 / 我的”补充简洁图标，继续使用原生 tabBar，不引入自定义导航组件。

## 5. 页面方案

### 5.1 首页

```text
┌────────────────────────────┐
│ 今日待处理标签              │
│  2  今天先处理 2 项         │
│ [已过期 1] [7天内 1]  共3项 │
└────────────────────────────┘
  搜索物品
 [全部分类] [全部位置]

 已过期                         1
 ┌ 09/06  酸奶        已过期1天 ┐
 └────────────────────────────┘
 3 天内到期                     1
 ┌ 09/09  披萨          还有2天 ┐
 └────────────────────────────┘
                         ＋ 新增
```

- 用深色主视觉替换当前“标题 + 三等分统计”，形成首屏中心；
- 搜索保持单行，筛选改为轻量胶囊按钮，已筛选时显示绿色描边与清除入口；
- 分组标题增加间距与数量，取消纯装饰竖线，状态通过标题色和日期标签体现；
- 列表行继续保持轻量，不改成层层套卡；日期标签按状态使用红、橙、绿的浅色底；
- 悬浮新增按钮缩短为“＋ 新增”，固定在 tabBar 上方安全区，避免遮挡列表信息；
- 空状态沿用“标签”造型，并把“新增物品”作为唯一主操作。

### 5.2 新增 / 编辑页

- 顶部引导语保留宋体，但压缩说明文字，首屏尽快进入输入；
- 表单从三张同权卡片改为一张连续表单，只用分隔线区分“基本信息 / 到期信息 / 分类与提醒”；
- “到期信息”使用薄荷白弱背景，是表单中的唯一重点区；
- 日期录入方式继续使用双选项切换，但选中态使用白底、松针绿文字和轻阴影；
- 必填项只标必要星号，说明文案放到字段下方，不重复字段标题；
- 底部保存按钮固定在安全区上方，新增显示“加入库存”，编辑显示“保存修改”。

### 5.3 物品详情页

- 顶部“保鲜标签”展示物品名、到期日和大号状态文案，例如“已过期 1 天”；
- 状态色只用于顶部细带、状态数字和标签，不让整页变红或变橙；
- 物品信息改为无卡片的键值列表，“编辑”使用右上角图标按钮；
- 微信提醒压缩为一行状态说明 + 一个操作按钮，避免单独大卡片抢占空间；
- 处理区只突出“标记已用完”，数量减一为次按钮，丢弃和删除放入独立危险区；
- 保证同一操作只出现一次，所有按钮文案与反馈文案保持一致。

### 5.4 我的

- 页面标题简化为“我的保鲜设置”，减少口号式文案；
- 默认设置保留一张主容器，行间通过图标、标题和值建立扫读路径；
- 历史记录与设置拉开 `48rpx` 间距，搜索框和状态筛选使用首页同款控件；
- 空状态缩短垂直高度，避免页面中段出现大面积空白；
- 产品说明降为页尾弱信息，不与功能区竞争。

## 6. 交互与动效

- 页面进入仅让首页主数字和两枚状态标签做一次 `180–240ms` 的轻微上移淡入；
- 点击列表、筛选和按钮统一使用 `120ms` 的透明度或缩放反馈；
- 筛选后保持列表位置稳定，空结果直接给出“清除筛选”；
- 保存成功、标记用完等状态变化使用短反馈，不加入持续动画；
- 遵循 `prefers-reduced-motion`，关闭非必要过渡；触控区域不小于 `88rpx`。

## 7. 实施顺序

### 第一阶段：建立视觉中心

1. 在 `app.wxss` 统一颜色、字号、圆角和间距基础规则；
2. 改造首页今日待处理区、搜索筛选、列表日期标签和新增按钮；
3. 补齐 tabBar 与常用操作图标。

### 第二阶段：统一页面层级

1. 重排新增 / 编辑页连续表单；
2. 重排详情页状态标签与操作优先级；
3. 统一“我的”与历史记录控件。

### 第三阶段：状态与细节收口

1. 统一加载、空、错误、禁用、按压状态；
2. 检查长名称、极端数字、键盘顶起和安全区；
3. 在开发者工具和真机完成核心流程验收。

## 8. 验收标准

- 首屏 1 秒内能识别“今日待处理数量”和首个紧急物品；
- 每页最多一个强视觉区、一个主操作，不出现多个同权大按钮；
- 已过期、临期、安全在灰度环境下仍可通过文案区分；
- 320～430px 宽度下无横向溢出、按钮遮挡和文字截断；
- 新增、编辑、提醒、减量、用完、丢弃的业务流程不变；
- 开发者工具编译无错误和警告，真机检查滚动、触控、键盘与安全区；
- 最终以首页、表单、详情、我的四页对比截图确认视觉层级一致。

## 9. 本轮不做

- 不新增图表、家庭共享、智能推荐等产品功能；
- 不引入第三方 UI 库、自定义导航框架或复杂动画；
- 不使用大图背景和装饰插画掩盖信息层级问题；
- 不改动现有数据结构、云函数和临期计算规则。
