# 快速录入 P0/P1 实施与验收记录

更新：2026-09-08。产品依据：[quick-entry-product-design.md](./quick-entry-product-design.md)。

## 已实现的闭环

| 产品范围 | 当前实现 |
| --- | --- |
| P0 最近物品 | 新增入口、最多 6 个规范化去重名称、active/used_up 隔离查询；跨状态分页按时间边界继续读取，避免较旧条目挤掉新条目；复用非日期字段、无效配置确认、生产/到期日期清空 |
| 统一草稿 | 名称和日期展开；数量、单位、分类、位置、提醒可编辑；状态校验、到期计算、过期提示、勾选、删除、逐条结果、离开提示 |
| 文字 | 客户端及云函数共享确定性解析；明确日期、上海相对日、无年份月日、保质期、明确分类和位置、中文数量；分号/清晰停顿/连接词拆分最多 5 条；不补缺失日或生产日 |
| 语音 | 腾讯云官方 ASR SDK；按住录音、松开转写、移出取消、时长/30 秒上限、拒绝后设置入口；原文回填并进入同一解析器 |
| 拍日期 | 腾讯云官方 OCR SDK；独立日期取景、预览确认、重拍、单张相册、原照片重试；日期证据、保质期保留、无标签选择、冲突与倒序阻塞；只更新指定草稿 |
| 手动兜底 | 可选择多条中的一条完整填写；一次性内存传递合法字段，排除不确定日期；返回快录仍保留原文及其他草稿；完成后同步原草稿状态 |
| 保存重试 | 唯一保存链路 inventoryApi；稳定请求编号和原始提交快照；成功项不再提交，失败项单独重试且不计入批量按钮数字 |
| 数据边界 | 原文/照片不入库存；临时媒体按用户哈希目录隔离，服务端和客户端均清理；埋点仅包含来源、结果、耗时、数量、字段名 |

文字解析采用明确语义规则，不承诺任意自由叙述都能正确拆解；缺失或歧义留给用户确认。保留自定义 TEXT/STT/OCR 服务协议，腾讯云适配器无需自建代理。只有实际配置可用的语音和拍日期入口才显示。

## 已执行验证

- `npm run check`：类型检查、11 个测试文件 / 79 项测试、项目 JSON/云函数语法、两端解析器一致性检查通过。
- `git diff --check`：通过。
- 微信开发者工具：打开首页及快录页，最近接口实际返回 6 项。仓库基础库配置 3.8.10，本机私有配置覆盖为 3.17.2；最低版本兼容性仍需真机或切换基础库复核。
- 真实文字流程：`牛奶2盒9月12日到期；酸奶4杯9月15日到期` 生成两条可保存草稿，数量/单位/完整日期正确，按钮计数为 2。
- 真实手动兜底：第二条酸奶草稿带入完整表单（4 杯、2026-09-15），页面栈保留快录页和原始两条草稿。
- 返回流程：重新编译后的独立运行态检查确认返回 `pages/quick-entry/index`，两条草稿及原文保持不变，`manualHandoff` 恢复为 false。跨页面长 evaluate 请求本身会超时，因此使用返回后的独立页面快照核实结果。
- 已部署 `inventoryApi`、`quickEntryApi` 到当前关联环境，部署均返回 success。
- 直接调用已部署的 `quickEntryApi.parseText` 返回 `parserVersion: rules-v2`；生产日期 2026-09-01、保质期 2 年、位置药箱均正确。
- 云端幂等实测：同一请求编号两次保存返回相同 itemId，列表中只有一条匹配记录。验收专用记录已移入回收站后彻底删除。
- 单元测试覆盖多日期冲突、日期倒序不能用候选按钮绕过、闰年、缺少年/月/日、不完整草稿、取消后的迟到响应、指定草稿 OCR、照片失败保留、部分失败只重试原请求、跨用户媒体拒绝和近期分页去重。

## 仍需协助完成的上线验收

代码部署成功不代表识别服务已经开通。当前真实环境能力结果为 `voice: false`、`datePhoto: false`。

1. 在腾讯云开通一句话识别与通用文字识别（高精度版），确认计费；在 `quickEntryApi` 云端配置专用 `QUICK_ENTRY_TENCENT_SECRET_ID` / `QUICK_ENTRY_TENCENT_SECRET_KEY`。不要把密钥发到聊天或提交到仓库。若使用已有服务，按 [部署说明](./cloud-deployment.md) 配置对应接口。
2. 在微信公众平台更新隐私保护指引、第三方处理方说明和审核材料。录音/相机的权限描述不能写进不受支持的 `app.json.permission` 字段。
3. 核对云存储本人读写权限，并设置 `quick-entry/` 临时文件生命周期清理，兜底断网、进程退出和函数硬超时后的孤立媒体。
4. 用真机和两个微信账号验证录音、相机、相册授权/拒绝、30 秒停止、移出取消、弱网重试、安全区、最近物品和媒体隔离。模拟器和单元测试不能替代这些结果。

以上项目完成前，P1-B/P1-C 的真实端到端验收仍未完成，不应据此标记全部上线完成。
